# Como usar o Ômega

O Ômega lê o relatório que o Claude gerou (arquivo `.json`), deixa você decidir item por item e copia só as decisões para você colar de volta na conversa com o Claude.

## No computador
1. Baixe a pasta do repositório (botão verde **Code → Download ZIP**) e extraia.
2. Dê **duplo clique** em `index.html`. Ele abre no navegador.
3. Toque em **Ver exemplo** para testar, ou em **Abrir relatório** e escolha o arquivo `.json` do Claude (ou **Colar relatório**).
4. Toque na **bolinha** de cada item: vermelho = pendente, verde = liberado, azul = ajustar, cinza = ignorar.
5. No fim, toque em **Copiar decisões** e cole na conversa com o Claude.

Deixe `dicionario-ptbr.js` na mesma pasta do `index.html` (ele é usado pelo Revisor).

## No celular
1. Abra o endereço: **https://seinfrailheusprocessos-ship-it.github.io/omega/**
2. (Opcional) No menu do navegador, escolha **Adicionar à tela inicial** para virar um ícone.
3. Para levar as marcações do computador ao celular: no computador, aba **Estado → Copiar estado**; mande o texto para você mesmo (WhatsApp, e-mail); no celular, aba **Estado → colar o texto → Colar estado**.

## Se o endereço do celular não abrir
O GitHub Pages precisa estar ligado: no GitHub, abra o repositório → **Settings → Pages → Branch: main, pasta / (root) → Save**. Espere 1–2 minutos.

## Observações
- Tudo fica guardado só no navegador de cada aparelho. Limpar os dados do navegador apaga as marcações.
- Nada é enviado a ninguém. O Revisor confere o texto no próprio aparelho.
